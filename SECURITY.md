# Security Policy

## Supported versions

Only the latest version on the `main` branch and the latest published release receive security fixes.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues, discussions, pull requests, or other public channels.

Use GitHub's private vulnerability reporting feature for this repository when available. If it is unavailable, email `gmeilus@outlook.com` with the subject `Logseq Rig security report`.

Include the affected version or commit, environment, affected command or component, reproduction steps or proof of concept, impact, and any suggested mitigation. Sanitize graph content, credentials, and personal data before sending.

We will acknowledge a report within seven days, investigate privately, coordinate a fix and disclosure timeline with the reporter, and credit the reporter when they agree. Please do not send secrets that are not needed to reproduce the issue.
