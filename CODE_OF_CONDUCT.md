# Code of Conduct

We welcome contributions that are respectful, specific, and focused on improving Logseq Rig. Harassment, discrimination, threats, doxxing, and disruptive personal attacks are not acceptable.

Report conduct concerns privately to `gmeilus@outlook.com`. Please do not include confidential vulnerability details in a conduct report; use [SECURITY.md](SECURITY.md) for security issues.

Maintainers will acknowledge a report within seven days, review it privately, and may remove or decline contributions that violate this policy. Retaliation against a good-faith report is not acceptable.
